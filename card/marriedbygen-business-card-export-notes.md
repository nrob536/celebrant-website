## PDF Export Workflow (Inkscape)

1. Open `marriedbygen-business-card-print.svg` in Inkscape.
2. Ensure page size is exactly 96 x 61 mm.
3. Convert text to paths for print portability:
   - Select all text objects.
   - Path -> Object to Path.
4. Save a new export file (for example, `marriedbygen-business-card-print-outlined.svg`).
5. Export as PDF:
   - File -> Save As -> PDF.
   - Keep page size unchanged.
   - Ensure rasterization is disabled for vector elements.
6. Upload PDF to printer and disable any auto-scaling options.

## Final Preflight Checklist

- No guides visible in final upload file.
- Bleed remains at full 96 x 61 mm.
- All text/logo sits inside safe area.
- Card is uploaded at 100% scale with no fit-to-page.
